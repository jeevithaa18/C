## 💡 Why C?

C is widely used in systems programming and embedded development because it provides:

* Direct memory access
* Efficient and predictable performance
* Low-level hardware interaction
* Understanding of how memory works
* A strong foundation for embedded programming

Learning C will help me understand not only **how to write programs**, but also **how software interacts with hardware**.
